# Study Projects: Python Expert Systems

Учебные скрипты на Python с использованием экспертных правил, обработки строк и структурированных данных.

## Содержание репозитория:
1. **`names.py`** — Экспертная система для определения пола по имени и окончаниям фамилий на основе лингвистических маркеров.
2. **`travelexpert.py`** — Калькулятор расчёта стоимости поездок по Кыргызстану с учётом коэффициентов сложности горной местности.
